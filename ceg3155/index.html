What carries the marks

The midterm cannot be transferred to the final. A missed midterm is a lost 20 percent, so the date is worth protecting. It falls the evening after the Signal and System Analysis midterm.

Five assignments are set and the best four are counted, which leaves room for one to go badly. Three quizzes run with the best two counted, on the same principle. Quizzes, the midterm and the final are all written in person.
