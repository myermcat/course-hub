Sets 1 to 5 are the whole midterm syllabus. The midterm covers chapters 1 to 3, and those five sets are every posted problem from those chapters. Problems 3.19 and 3.20 appear in set 7 and belong to chapter 3, so they are fair game for the midterm even though the set is scheduled later.

None of this is handed in and none of it is worth marks. Three things confirm it. The marking scheme already adds to 100 percent without them. Every set has its full solution posted beside it, which no graded work would. No due date appears anywhere on the course page.

The marks come from the Friday tutorial quiz. Eleven quizzes run at the start of tutorial, the best ten count, and together they are worth 10 percent. Working the matching assignment set beforehand is the preparation for that quiz.

Where this comes from

Brightspace holds the lecture notes and nothing else for this course. There is no gradebook, no dropbox and no outline there. The assignments, the solutions and the schedule all live on Prof. Yao's own page at site.uottawa.ca/~jpyao, which is the source to check.

The files are served from a folder named for the old course code, ELG3120, and the page footer reads 2021. Both are stale labels on current material: the teaching assistants, rooms and midterm date all match this year.

The Solution column points at Prof. Yao's own copies on site.uottawa.ca. Opening one needs an internet connection, and the PDFs are not kept in this repository. The Questions column opens a page from the pages folder beside this one.

The problem pages show the assigned questions photographed from the textbook, which is under copyright. Each scan is the single page carrying a problem the course sets, with the assigned parts ringed. The book itself is not kept here and neither is any chapter of it.
