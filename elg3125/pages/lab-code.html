Lab 4 · Property and Combination of LTI Systems

Example 1Cascade: combine two systems into one

An LTI discrete-time system has input $x[n]$ and output $y[n]$, initially at rest.

$$y[n] - \frac{5}{6}y[n-1] + \frac{1}{6}y[n-2] = x[n]$$

Its output becomes the input of a second system, also initially at rest.

$$z[n] + \frac{9}{20}z[n-1] + \frac{1}{20}z[n-2] = y[n]$$

Slides 10 and 11 ask: compute and display the impulse response of the equivalent system between $x[n]$ and $z[n]$.

Slide 11
n = 0:20;                  % time axis, 21 samples

% system 1:  y[n] - (5/6)y[n-1] + (1/6)y[n-2] = x[n]
B1 = [1 0 0];              % x side: only x[n], zeros pad to match A1
A1 = [1 -5/6 1/6];         % y side: y[n], y[n-1], y[n-2], signs as written

% system 2:  z[n] + (9/20)z[n-1] + (1/20)z[n-2] = y[n]
B2 = [1 0 0];
A2 = [1 9/20 1/20];

h1 = impz(B1,A1,n);        % impulse response of system 1
h2 = impz(B2,A2,n);        % impulse response of system 2

h3 = conv(h1,h2);          % impulse response of the combined system

figure;
stem(0:length(h3)-1,h3,'Linewidth',2);   % conv output is longer than n, so build its own axis

conv returns length(h1)+length(h2)-1 samples, 41 here. That is why the stem axis is built as 0:length(h3)-1. Passing n errors on a length mismatch.

Slide 12 then asks: given an input $x[n] = e^{-n}$, observe the output of the two cascaded systems and the output of the equivalent system.

Slide 12
% given an input exp(-n), observe the output of two cascaded systems
% and the output of the equivalent system

x  = exp(-n);              % elementwise, since n is a vector

y  = filter(B1,A1,x);      % run system 1 on x
z  = filter(B2,A2,y);      % feed y into system 2: the literal cascade
z2 = filter(h3,1,x);       % A=1 means no feedback, so this convolves x with h3

figure;
subplot 311
stem(n,x,'Linewidth',2);
title('Input signal');

subplot 312
stem(n,z,'Linewidth',2);
title('Output of the two cascaded systems');

subplot 313
stem(n,z2,'Linewidth',2);
xlabel('n');
title('Output of the equivalent system');

The bottom two plots come out identical. Two systems in series equal one system whose impulse response is the convolution of theirs.

Example 2Stability: check whether the system is stable

Check whether these LTI systems are stable. Each is initially at rest.

$$\text{(1)}\quad \frac{d^{2}y(t)}{dt^{2}} - 5\frac{dy(t)}{dt} + 4y(t) = x(t)$$ $$\text{(2)}\quad \frac{d^{2}y(t)}{dt^{2}} + 5\frac{dy(t)}{dt} + 4y(t) = x(t)$$ $$\text{(3)}\quad y[n] - \frac{1}{4}y[n-2] = x[n]$$ $$\text{(4)}\quad y[n] + \frac{2}{3}y[n-1] - y[n-2] = x[n]$$

The method, from slide 16. Evaluate the impulse response first. A bounded $h$ integrates or sums to something bounded, so the system is stable. An unbounded $h$ means unstable.

Slide 17 · system 1 · not stable
t  = 0:0.01:1;             % time axis, continuous so a fine grid
b1 = [0 0 1];              % x side: only x(t), so the 1 goes LAST
a1 = [1 -5 4];             % y side: highest derivative FIRST
h1 = impulse(b1,a1,t);     % continuous-time impulse response

figure;
plot(t,h1,'Linewidth',2);  % continuous signal, so plot
Slide 18 · system 2 · stable
% system 2
t2 = 0:0.01:5;
b2 = [0 0 1];
a2 = [1 5 4];              % only the middle sign changed
h2 = impulse(b2,a2,t2);

figure;
plot(t2,h2,'Linewidth',2);
Slide 19 · system 3 · stable
% system 3
n1 = 0:1:30;
b3 = [1 0 0];
a3 = [1 0 -1/4];           % the 0 holds the empty y[n-1] slot
h3 = impz(b3,a3,n1);

figure;
stem(n1,h3,'Linewidth',2); % discrete signal, so stem
Slide 20 · system 4 · not stable
% system 4
n2 = 0:30;
b4 = [1 0 0];
a4 = [1 2/3 -1];
h4 = impz(b4,a4,n2);

figure;
stem(n2,h4,'Linewidth',2);

Slide 20 is headed "(3)" in the deck. It is the fourth system. The heading was not renumbered when the slide was copied.

Example 3Invertibility: find the inverse system

Which of the three systems below is the inverse of this one?

$$y[n] - \frac{5}{6}y[n-1] + \frac{1}{6}y[n-2] = x[n]$$ $$\text{(a)}\quad y[n] = \frac{1}{6}x[n] - \frac{5}{6}x[n-1] + x[n-2]$$ $$\text{(b)}\quad y[n] = x[n] - \frac{5}{6}x[n-1] + \frac{1}{6}x[n-2]$$ $$\text{(c)}\quad \frac{1}{6}y[n] - \frac{5}{6}y[n-1] + y[n-2] = x[n]$$

Then, given an input $x[n] = e^{-n}$, observe the input and the output of each cascade.

Slide 24 · the four systems
% original system:  y[n] - (5/6)y[n-1] + (1/6)y[n-2] = x[n]
b0 = [1 0 0];
a0 = [1 -5/6 1/6];

% candidate (a):  y[n] = (1/6)x[n] - (5/6)x[n-1] + x[n-2]
b1 = [1/6 -5/6 1];
a1 = [1 0 0];

% candidate (b):  y[n] = x[n] - (5/6)x[n-1] + (1/6)x[n-2]
b2 = [1 -5/6 1/6];
a2 = [1 0 0];

% candidate (c):  (1/6)y[n] - (5/6)y[n-1] + y[n-2] = x[n]
b3 = [1 0 0];
a3 = [1/6 -5/6 1];

Two systems are inverses when their cascade is the identity. So the test is whether $h_0 * h$ comes out as $\delta[n]$, a single spike at $n = 0$.

Slide 25 · the test
n = 0:20;
h0 = impz(b0,a0,n);
h1 = impz(b1,a1,n);
h2 = impz(b2,a2,n);
h3 = impz(b3,a3,n);

h_conv1 = conv(h0,h1);     % cascade of original with candidate (a)
h_conv2 = conv(h0,h2);     % with candidate (b)
h_conv3 = conv(h0,h3);     % with candidate (c)

figure;
subplot 311
stem(0:length(h_conv1)-1,h_conv1,'Linewidth',2);
subplot 312
stem(0:length(h_conv2)-1,h_conv2,'Linewidth',2);
subplot 313
stem(0:length(h_conv3)-1,h_conv3,'Linewidth',2);
xlabel('n');

Only h_conv2 is a delta function, so candidate (b) is the inverse. Candidate (c) reaches $10^{10}$.

Slide 26 · confirming with a real input
x  = exp(-n);
y0 = filter(b0,a0,x);      % push x through the original system
y1 = filter(b1,a1,y0);     % then through each candidate
y2 = filter(b2,a2,y0);
y3 = filter(b3,a3,y0);

figure;
subplot 411
stem(n,x,'Linewidth',2);
title('x[n]');
subplot 412
stem(n,y1,'Linewidth',2);
title('Output of cascade system (h0,h1)');
subplot 413
stem(n,y2,'Linewidth',2);
title('Output of cascade system (h0,h2)');
subplot 414
stem(n,y3,'Linewidth',2);
title('Output of cascade system (h0,h3)');

y2 comes back identical to the input, which is what an inverse does.

Lab 5 · Fourier Series

ExampleFourier series: synthesize a square wave

A square wave $x(t)$ has period $T$, with $T_1 = 0.5$ and $T = 4$.

$$x(t) = \begin{cases} 1, & |t| < T_1 \\ 0, & T_1 < |t| < T/2 \end{cases}$$

Its Fourier series coefficients are

$$a_0 = \frac{2T_1}{T} \qquad a_k = \frac{2\sin(k\omega_0 T_1)}{k\omega_0 T} \qquad \omega_0 = \frac{2\pi}{T}$$

Rebuild $x(t)$ from $a_0$ and $a_k$ using the truncated synthesis, and observe the effect of raising the number of terms.

$$\hat{x}(t) = a_0 + 2\sum_{k=1}^{(N_a-1)/2} |a_k|\cos(k\omega_0 t + \angle a_k)$$
Slide 10
clear; close all
t  = -4:0.01:4;
N  = length(t);
T  = 4;        % period of the square wave
T1 = 0.5;      % duty cycle of the square wave

% synthesize the signal in the frequency domain
N_a = 81;      % the number of frequencies to synthesize the signal
a0     = 2*T1/T;
omega0 = 2*pi/T;

x_tem = zeros(1,N);                % running sum, same length as t
for k = 1:1:(N_a-1)/2              % N_a is odd, so this is a whole number
    ak    = 2*sin(k*omega0*T1)/(k*omega0*T);              % Fourier series coefficient
    x_tem = 2*abs(ak)*cos(k*omega0*t+angle(ak)) + x_tem;  % add this harmonic
end

x2 = a0 + x_tem;   % synthesized signal (with DC component)
figure;
plot(t,x2,'Linewidth',2);

The loop stops at $(N_a-1)/2$. The sum is symmetric in $k$, so $N_a$ terms means that many harmonics on each side plus the DC term. That is why slide 6 insists $N_a$ is odd.

abs and angle give $|a_k|$ and $\angle a_k$, which is what the real form on slide 6 needs. Using ak directly leaves complex numbers in the result.

x_tem is preallocated with zeros(1,N) so the loop can accumulate into it.

Raising $N_a$ from 21 to 81 sharpens the edges, and the overshoot at each jump never goes away. That is the Gibbs phenomenon, and it is the point of the four panels on the slide.
