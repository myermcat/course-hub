Deliverables

Where the material lives

The project list is not a topic in the Brightspace content tree. It is a link inside the description text of Content → Project Deliverables → Information for the project, which Brightspace does not render in the topic list. The milestone table and the confidentiality form are in that same module.

Per-section deadlines work the same way, written into each lab topic's description. The dropbox does not show them. Announcements are Prof. Lakhani's main channel, and email is answered within one business day.

The course home is Brightspace organisation unit 602711. Source material stays in the GNG2101 folder on disk, and this page is published from the course-hub repository.
